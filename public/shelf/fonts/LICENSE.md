# ClashDisplay-Medium.woff

Clash Display by Indian Type Foundry, distributed through
[Fontshare](https://www.fontshare.com/fonts/clash-display) under the
**Fontshare Free License** — free for personal and commercial use, no
attribution required, redistribution of the font files themselves not
permitted as a standalone product.

This copy is served only as a texture source for the book spines in the 3D
scene. The rest of the site loads the same family from Fontshare's CDN, which
`index.html` already does.

**Why a WOFF and not a WOFF2.** drei's `<Text>` renders through
`troika-three-text`, which reads TTF, OTF and WOFF but not WOFF2. Fontshare
serves all three; this is the one that parses.
